# Vida

App pessoal (PWA) para organizar a vida: hoje, dinheiro, agenda, projetos, faíscas, Magnetic e Espelho.

- Publicado automaticamente pelo GitHub Pages a cada push na branch `main`.
- Para instalar no iPhone: abra o link no Safari → Compartilhar → **Adicionar à Tela de Início**.
- Os dados ficam salvos no próprio aparelho (use **Ajustes → Baixar backup** de vez em quando).
